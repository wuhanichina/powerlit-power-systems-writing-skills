# Innovation Exemplar DOI Map

Use this map after the innovation route is selected. These DOI seeds are
verified PowerLit records intended for retrieval of argument structure,
section functions, case-evidence order, and figure-discussion moves. They are
not universal closest competitors and must not be cited merely because they
appear here.

Retrieve each candidate from PowerLit by DOI, inspect the actual record, and
keep it only when its minimum research object and technical object are relevant
to the current paper. Learn structure; never copy source sentences,
contribution wording, captions, or distinctive phrases.

## Retrieval Procedure

For the selected innovation type:

1. retrieve the listed DOI from PowerLit and confirm the record is available;
2. retrieve 2–4 current papers matching
   `venue + minimum research object + primary innovation axis + technical
   object + novelty magnitude`;
3. build a compact exemplar pack containing section moves, paragraph functions,
   evidence order, figure roles, result-discussion moves, and conclusion
   boundary;
4. prefer the current project's closest papers over these seeds when they
   conflict;
5. write only from the current project's model, variables, and evidence.

The DOI map is a retrieval index, not a citation list. A DOI may appear under
more than one innovation type when the paper demonstrates more than one useful
argument function.
